## 多机型 UI 开发支持

- 新增 X1D 50C（1.20.0 / 1.21.0 / 1.25.0）、X1D II 50C（1.0.1–1.5.2 的已列明版本）、X2D 100C（1.0.5 / 4.2.0）和 907X / CFV II 50C（1.5.2）。完整版本及实测记录见[验证说明](https://github.com/derrickyau9/Hasselblad-X2D-II-QEMU-DevKit/blob/v0.2.0/docs/VERIFICATION.md)。
- 自动选择 Android ARM32、Android ARM64 或 Linux ARMhf 环境；示例 App 可按对应架构编译、运行。
- 修复旧版 UI 的缓冲区步长及局部刷新问题；增加机型选择和 F1–F5 虚拟按键。
- 38 项自动测试通过，三种架构的原厂 UI 和示例 App 均已在 Windows 上运行验证。

下载并解压 **X2DII-DevKit-Windows-x64.zip**，运行 EXE，导入自行下载的官方 `.cim` 固件。首次使用会下载运行环境；X1D 另需约 78 MB 的运行库。

本版本用于 UI 开发，硬件服务使用模拟数据；不支持拍摄、实机刷写或 907X / CFV 100C。新增机型尚未在 macOS 上验证。固件不随发布包分发。

## Multi-model UI development

- Adds X1D 50C (1.20.0 / 1.21.0 / 1.25.0), X1D II 50C (listed versions from 1.0.1 to 1.5.2), X2D 100C (1.0.5 / 4.2.0), and 907X / CFV II 50C (1.5.2). See the [version matrix and verification record](https://github.com/derrickyau9/Hasselblad-X2D-II-QEMU-DevKit/blob/v0.2.0/docs/VERIFICATION.md).
- Selects Android ARM32, Android ARM64 or Linux ARMhf runtime and example-app compilation for the chosen firmware.
- Fixes legacy UI buffer stride and partial repaint handling; adds camera selection and virtual F1–F5 keys.
- 38 automated tests pass. Original UIs and example apps were exercised on Windows across all three ABIs.

Extract **X2DII-DevKit-Windows-x64.zip**, run the EXE, and import your own official `.cim` firmware. Runtime setup downloads dependencies on first use; X1D needs an additional approximately 78 MB of libraries.

This is a UI development environment with simulated hardware services. Capture, camera flashing and 907X / CFV 100C are unsupported. Additional models have not been verified on macOS. No firmware is bundled.
